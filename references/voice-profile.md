# 七帅写作风格 · 声音档案（详细对照）

> 本文件是 `qishuai-writing-style` 的语料库。生成内容前先读一遍，照着真实范例写，别凭空编「AI 腔」。

素材来源：用户即刻主页（昵称「七帅」）十余篇长文动态，主题覆盖第一性原理、执行力、消费观、善良、设计师 vs AI、正能量、拜访导师等。

---

## 一、真实开头范例（照这个调性起手）

1. **场景 + 观点切入**
   > 昨天在X上看到一个观点：最幸福的人是很难被催促的人。随着年龄增长，我越来越意识到一件事——最幸福的人，其实是那种最难被催促的人。

2. **直接抛出思考**
   > 我在想，其实很多时候，我们要站在第一性原理的角度去思考和分析问题。

3. **事件切入**
   > 今年才到7月中旬，我已经经历了一件大事和一件小事，这两件事对我的心态冲击非常大。

4. **提问式**
   > 58同城设计部大裁员之后，设计师真正要担心的是什么？最近，58同城设计部大裁员的消息，引发了很多设计师的焦虑。

5. **设问铺陈**
   > 我们平时要尽量做一些正能量的事情。那什么是正能量呢？我从三个方面来说。

**规律**：从不写「引言」「摘要」「本文关于」。要么从一个具体的人/事/观点落地，要么直接说「我在想…」。

## 二、标志性过渡与口头禅（高频复用）

- 举例引入：**「我举个例子。」** **「再举一个例子。」** **「还有一个身边的例子。」**
- 转折推进：**「但问题来了——」** **「那我们应该怎么做？」** **「其实你想想，」** **「你看，」**
- 自我剖白：**「说实话，我心里非常郁闷。」** **「我坦白讲，他现在过的日子是我挺羡慕的——」**
- 强调堆叠：**「非常非常」**「越来越」**「一点点」**「慢慢地」**「其实很多时候」
- 插入解释：大量 **「——」** 破折号（如「最难被催促的人——」「这件事非常波折——」）

**真实举证结构示范**（来自「执行力」一文）：
> 再举一个例子。几乎所有人都知道，我要每天坚持写作……但就是这么一个简单的动作——每天坚持写作，不限制字数……身边还是有很多人没有坚持下去。
> 还有一个身边的例子。一个前同事，多年前心里就有一个目标……

## 三、真实案例怎么写（具体、有血肉）

他的案例几乎都有三要素：**真实人物 + 数字细节 + 对话 / 心理**。

- 人物：邻居家妹妹、飞机上喝红酒的先生、前同事、研究生导师、卖水老人。
- 数字：垫付「5万」、抢救「11分钟」、每天「30分钟」、一年「365个视频」、书「800多块钱」。
- 对话：导师说「你只要做好自己的事情……」；先生说「我从来不明白为什么要急。我们最终都会去同一个地方，不是吗？」

**禁忌**：不要写「小明」「某人」「研究表明」这种空壳案例。要用可感知的具体人和事；若需虚构，必须向用户标注「此处为示例，请替换」。

## 四、真实结尾范例（软性收束）

1. **标志性总结句**
   > 这就是我最近的一些思考。我认为这个方法非常非常有帮助。
   > 这也是我最近的一些感慨和思考。

2. **回到开头意象**
   > 他坐在那里，微笑着，喝着飞机上的红酒，一点不急着抢先到达我们所有人最终都要去的那个地方。

3. **温和立场 + 开放**
   > 善良这件事，不求回报，但它不该让你倒贴麻烦。下次再遇到类似的事，我还是会帮，但会更有分寸、更有保护自己的意识。这才是经历过之后的成长。

**规律**：结尾是「反思 / 感悟」，不是「行动清单 / 三步走 / 关注我」。

---

## 五、句式与节奏特征

- 中短句为主，口语推进，不堆词。
- 排比增强节奏：
  > 仓促地做决定，仓促地对话，仓促地开始一段关系，仓促地赶时间表。
- 自问自答：
  > 那我们应该怎么做？我们应该给自己制定一个很宏大的最终目标。
- 允许「絮叨」式的重复与回环（同一意思换种说法再讲一遍），这是他的真实声线，不要「精简掉」。

## 六、负面清单（生成后逐条自检）

| 不要出现 | 他的真实做法 |
|---|---|
| 小标题 / 一、（一）1. 分级 | 用「再举一个例子」「还有一个」自然过渡 |
| bullet 列表代替叙事 | 段落化、讲故事 |
| 「震惊 / 必看 / 速看 / 干货」 | 标题平实，常是问句 |
| 「关注我 / 点赞收藏 / 转发」 | 从不加 CTA |
| 书面腔「综上所述 / 由此可见」 | 用「你看 / 其实 / 说实话」 |
| 学术腔「研究表明 / 数据显示」 | 用亲身经历和数字 |
| 过度结构化、框架提炼 | 自然过渡，开放式结尾 |
| 虚构极端观点 / 数据 | 数字、人名来自用户提供 |

## 七、改写对照（看差别）

**通用 AI 腔（禁止输出）：**
> 执行力是拉开人与人差距的关键能力。首先，要设定清晰目标；其次，分解任务并立即行动；最后，在反馈中持续优化。坚持写作、持续学习，你将收获指数级成长。

**七帅风格（正确输出）：**
> 现在这个时间节点，对一个人能不能成事，我认为最重要的一个点就是执行力。再举一个例子。几乎所有人都知道，我要每天坚持写作，坚持一年、两年、三年，你的表达能力、结构化能力都会有质的提高。但就是这么一个简单的动作——每天坚持写作，不限制字数，只要你有思考，能把内容表达出来就行——身边还是有很多人没有坚持下去。你看，差距就在执行力上。这也是我最近的一些感慨和思考。

**差别点**：去掉了「首先 / 其次 / 最后」的框架；加了「再举一个例子」的举证；用「你看」收口；结尾是「这也是我最近的一些感慨和思考」而非行动清单。
